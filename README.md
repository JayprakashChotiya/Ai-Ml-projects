## 1. Credit Card Fraud Detection Using Machine Learning

**Self Project | Jan 2026 – Mar 2026**

Built a fraud detection system to identify fraudulent transactions in a highly imbalanced dataset.

### Key Work
- Trained **Logistic Regression, Random Forest, and XGBoost** models on 284,807 real-world transactions.
- Addressed severe class imbalance with **SMOTE oversampling** and cost-sensitive learning.
- Evaluated models using **PR-AUC**, achieving scores of 0.72, 0.82, and 0.885 respectively.
- XGBoost achieved **85% recall and 89% precision** on fraud detection.
- Used **SHAP** for model explainability and interpretation of important features.

### Technologies
`Python` `Pandas` `Scikit-learn` `XGBoost` `SMOTE` `SHAP` `Matplotlib`

## 2. Portfolio Optimization & Risk Analysis

**Course Project | Prof. Bimal Kishor Sahoo, IIT Kharagpur | Sep 2024 – Nov 2025**

Built and validated optimized equity portfolios for the Indian market using Modern Portfolio Theory, risk measures, and realistic backtesting.

### Key Work
- Constructed **Minimum Variance** and **Maximum Sharpe** portfolios across 10 NSE-listed equities.
- Minimum Variance Portfolio: **8.2% return, 0.10 Sharpe Ratio**.
- Maximum Sharpe Portfolio: **18.5% return, 0.83 Sharpe Ratio**.
- Compared optimized portfolios against **Nifty 50** and equal-weight portfolios.
- Assessed downside risk using **95% VaR (1.10–1.16%)** and **CVaR (1.58–1.79%)**.
- Evaluated portfolio performance using risk-adjusted performance metrics and backtesting.

### Technologies
`Python` `Pandas` `NumPy` `Matplotlib` `Portfolio Optimization` `VaR` `CVaR`

## 3. GARCH/EGARCH Volatility Modeling & VaR Backtesting

**Self Project | May 2024 – Aug 2024**

Analyzed Indian equity and currency market volatility using GARCH-family models and evaluated Value-at-Risk estimates through statistical backtesting.

### Key Work
- Modeled daily **Nifty 50 equity volatility** using GARCH(1,1).
- Estimated volatility persistence and asymmetric leverage effects using **EGARCH**.
- Backtested **95% VaR** using the Kupiec test.
- Observed a **6.1–6.4% VaR breach rate** against the expected 5.0% rate.
- Compared volatility behavior during the **COVID-19 and IL&FS crisis periods**.
- Analyzed USD/INR and Nifty 50 volatility persistence.

### Technologies
`Python` `Pandas` `NumPy` `Statsmodels` `GARCH` `EGARCH` `VaR` `Matplotlib`

## 4. Telecom Customer Churn Prediction & Customer Retention Analysis

**Self Project | Dec 2023 – Feb 2024**

Developed machine learning models to identify high-risk customers and generate insights for targeted customer retention strategies.

### Key Work
- Performed EDA on **7,043 customers** to identify major churn patterns.
- Analyzed contracts, services, payment methods, tenure, and demographic characteristics.
- Compared **Logistic Regression, Decision Tree, Random Forest, and XGBoost** models.
- XGBoost achieved **67.0% PR-AUC**.
- Optimized the XGBoost model using threshold tuning at **0.3**.
- Achieved **76.5% recall, 63.1% F1-score, and 84.7% ROC-AUC**.

### Technologies
`Python` `Pandas` `Scikit-learn` `XGBoost` `Matplotlib` `Seaborn`

## 5. USA Regional Sales Analysis

**Self Project | Feb 2024 – Mar 2024**

Analyzed five years of U.S. sales data to identify growth opportunities, profitability drivers, seasonal trends, and regional performance gaps.

### Key Work
- Consolidated and cleaned multi-source **sales, customer, product, and budget data** using SQL and Python.
- Engineered profit-margin metrics and performed regional, product, and customer-segment analysis.
- Identified **Products 25 and 26** as contributing 25% of total sales, with California leading in revenue and orders.
- Found the **West region** to have the highest overall sales.
- Benchmarked regional revenue KPIs and built **Power BI dashboards** to analyze sales performance and customer segments.
- Found that the **Wholesale segment contributed 54% of total sales**.

### Technologies
`SQL` `Python` `Pandas` `Power BI` `Excel` `Data Analysis`
